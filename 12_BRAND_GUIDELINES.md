# KODELUMA BRAND GUIDELINES

## Essence
Kodeluma = Kode + Luma (asosiasi cahaya/pemahaman). Nama merupakan usulan brand dan **belum merupakan verifikasi legal merek dagang**. Tagline `Learn. Code. Create.` Endorsement `by Azzam Codex`. Ditujukan ke pemula, mahasiswa, dan self-taught developer Indonesia.

## Aset resmi paket
- `assets/kodeluma-logo-horizontal.png`: horizontal wordmark transparan.
- `assets/kodeluma-logo-horizontal.webp`: versi web optimized.
- `assets/kodeluma-icon.png`: icon crop persegi dengan kanvas alpha.
- `assets/kodeluma-favicon.png`: icon 64px (preview/browser image).
- `assets/design-tokens.css`: CSS token design system untuk frontend.

## Usage
- Logo horizontal di header/footer/slide. Jangan di-stretch, jangan memberi glow, drop shadow tebal, stroke, gradient sendiri.
- Ukuran nav desktop 150–180px, mobile 124–150px; jaga whitespace ikon min. 8px di ukuran 160px.
- Header background putih/very light dan logo navy. Saat logo diperlukan di navy/dark, gunakan versi inversi yang **dibuat dan direview lebih lanjut**; jangan asal menambah CSS filter ke logo brand.
- Icon digunakan sebagai social profile/favicon/app tile. Jangan melabelinya sebagai logo universitas/sertifikat berakreditasi.
- Brand assets generatif dapat punya artefak kecil; lakukan pemeriksaan akhir sebelum produksi cetak. PNG bukan file SVG editable.

## Palette
Primary blue #2563EB; navy #10243A; amber #F4B544; canvas #F8FAFD; border #E2E9F1. Gunakan warna logo aktual dan palet token untuk keseluruhan UI. Brand tidak perlu mencampur warna PENS kecuali instruksi tugas/desain menuntutnya (proyek ini produk tersendiri).

## Naming & domain
Rekomendasi utama `kodeluma.azzamcodex.dev`, alias potensial `kodeluma.azzamcodex.id`. Keduanya **belum disetel otomatis** oleh paket dokumen ini. Konfirmasi DNS, HTTPS, dan konflik merek sebelum peluncuran komersial.
