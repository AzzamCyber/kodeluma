## Learning path: Mulai dari Nol
- **Tahap 1: HTML Dasar** — mengenal struktur halaman web.
  1. `Apa Itu HTML?` (teori, struktur dokumen pertama).
  2. `Tag, Elemen, dan Atribut` (contoh h1, p, a, img; latihan perbaiki markup).
  3. `Membuat Halaman Profil` (semantic structure, navigasi sederhana).
  - Quiz contoh: fungsi tag `<a>`, elemen heading, fungsi alt image; server stores answers.
  - Project: `Halaman Profil Sederhana` (wajib HTML semantic, 1 gambar lokal, link navigasi).
- **Tahap 2: CSS Fundamental** — memperindah dan merespons layar.
  1. `Mengenal Selector CSS` (class, id, element, specificity awal).
  2. `Warna, Tipografi, dan Spacing` (box model, rem, warna).
  3. `Flexbox dan Layout Responsif` (media query & gap).
  - Quiz contoh: `display:flex`, margin vs padding, selector class.
  - Project: `Kartu Produk Responsif` (card, CTA, breakpoint mobile).
- **Tahap 3: JavaScript Pemula** — interaksi pertama.
  1. `Variabel dan Tipe Data` (`let`, `const`, string, number, boolean).
  2. `Percabangan dan Perulangan` (`if`, `for`, praktik).
  3. `DOM dan Event` (click button & update text safely).
  - Quiz contoh: let/const, kondisional, event click.
  - Project V2 optional: `To-do List Sederhana`.

## Project grading (human review, no fake AI)
- **Halaman Profil Sederhana**: valid semantic HTML (40%), navigasi/link jalan (30%), kerapian konten (30%). Submission URL + catatan.
- **Kartu Produk Responsif**: CSS layout mobile (40%), readability/spacing (30%), card states & CTA (30%). Submission URL + catatan.
- Reviewer admin mengisi feedback singkat. Jangan klaim source code sudah dijalankan otomatis.
